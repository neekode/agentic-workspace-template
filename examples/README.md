# Example projects

These scenarios show what the workflow can do. Replace their placeholders with
information you choose to provide; no private household data or real deck list is
bundled. Each README owns its project notes and next steps. Use the shared
[session commands](../docs/workflow.md#session-requests) across the examples.

- [Files](files/README.md): inventory and reorganize music or pictures.
- [Magic: The Gathering](magic/README.md): research tools, retrieve a deck and review it.
- [Automation](automation/README.md): evaluate cross-ecosystem software.

These folders share the parent Git history. Independent checkouts are optional;
see the [workflow reference](../docs/workflow.md). Tool installation and live
connections are separate from reading and trying the examples.
