# Example projects

Choose a scenario and adapt it to your own goal and existing tools. Each README
owns its project notes and next steps. Use the shared
[session commands](../docs/workflow.md#session-requests) across the examples.

- [Files](files/README.md): inventory and reorganize music or pictures.
- [Magic: The Gathering](magic/README.md): research tools, retrieve a deck and review it.
- [Automation](automation/README.md): evaluate cross-ecosystem software.

For your own project folders or independent checkouts, see the
[workflow reference](../docs/workflow.md#add-your-projects).
